Aula 9 – Mini Project 🚀

1️⃣ Explore – Preparing Your Mini Project

Agora você vai começar seu mini projeto em inglês 🎯

Nesta aula vamos juntar:

  • this / that
  • these / those
  • a / an / the
  • objetos
  • frases de tecnologia
  • apresentação pessoal

📚 Leia o texto abaixo e tente traduzir sozinho.

Today I am preparing a mini project presentation.

I have a computer, a keyboard and a notebook on my desk.

The computer is connected to the internet.

These are my project files and those are my notes.

I am practicing my English and my pronunciation.

I want to present a simple website for my class.

The website has a menu, images and buttons.

My teacher says the project looks very good.

I feel excited because this is my first presentation in English.

2️⃣ Speaking Guided 🎙️

Repita as frases:

This is my project.

These are my files.

The website is working.

I am presenting my project.

3️⃣ Pronunciation Tips 🔊

Algumas palavras importantes para praticar:

Project → pró-jéct

Website → uéb-sáit

Presentation → pré-zen-têi-shon

English → ín-glish

💡 Dica:

Fale devagar primeiro. Depois tente aumentar a velocidade naturalmente.

4️⃣ Listening 👂

Teacher: This is a great project.

Student: Thank you! These are my project files.

Teacher: The website looks very good.

Este é um ótimo projeto. Obrigado! Estes são meus arquivos do projeto. O site parece muito bom.

5️⃣ Mission – Mini Presentation 🎯

Monte sua mini apresentação usando as frases abaixo:

Hello! My name is Bob.

This is my project.

The website is about technology.

These are my files.

Thank you!

Agora tente falar tudo em sequência 🎙️

6️⃣ English + Technology 💻

database – banco de dados
server – servidor
upload file – enviar arquivo
download file – baixar arquivo
responsive design – design responsivo
source code – código-fonte
user interface – interface do usuário

Frases úteis:

The server is online.

This is the source code.

These are the project files.

The user interface looks good.
