Aula 8 – Review Mission 🚀

1️⃣ Review Mission – Revisão Geral

📚 Nesta aula vamos revisar os principais conteúdos aprendidos até agora:

  • This / That
  • These / Those
  • a / an / the
  • Singular e plural
  • Objetos e tecnologia
  • Frases usadas no mundo real

Agora leia o texto abaixo e tente traduzir sozinho(a).

Translate

(Texto para tradução)

Today I am in a computer lab with my friends.

This is a computer and this is a keyboard.

These are our projects and these are our notebooks.

The teacher is helping a student with an error in the code.

Those are developers on the screen and those are their applications.

We are learning programming and we are building a website together.

It is a fun class and the students are very excited.

2️⃣ Speaking Review 🎙️

Repita as frases abaixo:

This is my computer.

These are my projects.

3️⃣ Listening 🎧

Teacher: This is a project.

Teacher: These are applications.

Teacher: That is an error.

Teacher: Those are students.

Este é um projeto. Estas são aplicações. Aquilo é um erro. Aqueles são estudantes.
